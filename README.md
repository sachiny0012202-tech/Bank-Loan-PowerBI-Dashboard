# Bank Loan Analytics Dashboard

## Project Overview
The Bank Loan Analytics Dashboard is a data analytics project designed to analyze bank loan applications, funded amounts, repayments, and loan performance using Power BI.

The project helps users understand loan trends, borrower information, and key financial metrics through interactive visualizations.

## Objectives
- Analyze total loan applications.
- Track funded loan amounts and total payments received.
- Compare good loans and bad loans.
- Understand loan status and repayment performance.
- Identify trends using charts, graphs, and KPIs.

## Tools and Technologies
- **Power BI Desktop** – Dashboard development and visualization
- **CSV** – Dataset storage
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs

## Dataset
The project uses a bank loan dataset stored in CSV format.

The dataset may include loan applications, loan amounts, interest rates, loan status, borrower details, and payment information, depending on the available columns.

## Key Dashboard Features
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income Ratio
- Good Loan vs. Bad Loan Analysis
- Loan Status Analysis
- Interactive filters and charts

## Project Workflow
1. Import the CSV dataset into Power BI Desktop.
2. Clean and transform the data using Power Query.
3. Create measures using DAX.
4. Design interactive charts and KPI cards.
5. Analyze loan performance and trends.
6. Save the report as a `.pbix` file.

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. If required, update the CSV file path in the data source settings.
4. Refresh the data to view the dashboard.
